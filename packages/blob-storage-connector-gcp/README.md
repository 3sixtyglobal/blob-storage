# TWIN Blob Storage Connector GCP

Blob Storage packages provide interoperable contracts and connectors for managing binary content across local, decentralised, and cloud environments. This package integrates blob workflows with [Google Cloud Storage](https://cloud.google.com/storage) for managed object storage.

## Installation

```shell
npm install @twin.org/blob-storage-connector-gcp
```
